Лабораторна робота №3: Інтеграція SQLite у Node.js бекенд

Даний проект реалізує збереження даних у реляційній базі даних SQLite з використанням TypeScript та Express.

🚀 Як запустити проект

Встановлення залежностей:

npm install


Запуск у режимі розробки:

npm run dev


При першому запуску файл бази даних data/app.db буде створено автоматично, а схема таблиць — ініціалізована.

Обмеження цілісності:

Використовується PRAGMA foreign_keys = ON.

Налаштовано ON DELETE CASCADE для постів (при видаленні юзера видаляються його пости).

🛠 API Ендпоінти

Користувачі (/api/users)

GET / — отримати всіх користувачів.

POST / — створити нового користувача.

Пости (/api/posts)

GET / — список постів (з використанням ORDER BY та LIMIT).

POST / — створення поста.

GET /with-authors — JOIN-запит: повертає пости разом з іменами авторів.

GET /stats — Агрегація: повертає кількість постів для кожного userId через COUNT(*).

⚠️ Попередження про SQL Injection

У цій лабораторній роботі SQL-запити формуються шляхом рядкової конкатенації (Template Literals):

`SELECT * FROM Users WHERE id = ${id}`


Чому це небезпечно?
Даний підхід дозволяє зловмиснику вставити шкідливий код у вхідні дані. Наприклад, якщо передати id як 1 OR 1=1, запит поверне всі дані з таблиці, ігноруючи фільтрацію. У наступних роботах це буде виправлено через параметризовані запити.

📁 Структура проекту

src/db/ — підключення та ініціалізація бази.

src/repositories/ — рівень доступу до даних (Data Access Layer), де зосереджений весь SQL.

src/routes/ — маршрутизація Express.

data/ — локальний файл БД (ігнорується git).
